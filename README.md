# 🩺 MedFlow – Smart Medicine Search

A sleek, multi‑theme web interface for searching medicines in Pakistan. Get instant details: price, dosage, side effects, interactions.

![MedFlow](https://img.shields.io/badge/status-live-brightgreen)  
**Live:** Open `index.html` in any browser (fully static).

---

## ✨ Features

- 🔍 **Real‑time search** – type any medicine name (e.g. Panadol, Brufen)
- 💊 **Detailed pharmaceutical info** – Uses, Dosage, Side effects, Precautions, Drug interactions
- 🌗 **6 elegant themes** – Frost, Void, Midnight, Luxe, Forest, Rose
- 📱 **Fully responsive** – works flawlessly on mobile, tablet and desktop
- 📚 **Built‑in API documentation** – modal with endpoint examples and error codes
- ⚡ **Zero dependencies** – pure HTML, CSS, JavaScript
