# 💊 MedFlow | Smart Medicine Search

### Find medicine prices, dosage & side effects instantly — for Pakistan

A sleek, multi-theme web interface for searching medicines. Get instant details: **price**, **dosage**, **side effects**, and **drug interactions** — zero dependencies, works offline, deploy anywhere.

## ✨ Features

- 🔍 **Real-time search** — type any medicine name (e.g. Panadol, Brufen) and get results as you type
- 💊 **Detailed pharmaceutical info** — Uses, Dosage, Side effects, Precautions & Drug interactions
- 🌈 **6 elegant themes** — Frost, Void, Midnight, Luxe, Forest, Rose
- 📱 **Fully responsive** — works flawlessly on mobile, tablet & desktop
- 📚 **Built-in API documentation** — modal with endpoint examples & error codes
- 🚫 **Zero dependencies** — pure HTML, CSS & JavaScript. No frameworks, no build step

## 🖥️ Live Demo

## 🚀 Quick Start

```bash
# 1. Clone the repository
git clone https://github.com/Ahsan-Dogar/Medflow.git
cd Medflow

# 2. Just open it
#    Double-click index.html — or serve it:
python -m http.server 8000
#    Then visit http://localhost:8000
```

---

## 🌐 Deploy to Vercel

A `vercel.json` is included for zero-config deployment:

```bash
npm i -g vercel
vercel
```
